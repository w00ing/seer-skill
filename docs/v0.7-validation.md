# Seer v0.7 validation

**Status: automated checks and synthetic Vision OCR passed; native window validation is blocked.** v0.7 is not yet fully validated. No successful live Accessibility assertion or OCR window capture is claimed.

Checked on macOS 27.0 (Apple Silicon), Python 3.9.6, Pillow 11.3.0, and Swift 6.4. Display-scale behavior for the new semantic commands remains unverified.

## Completed checks

| Area | Observed result |
|---|---|
| Automated regression suite | All 78 unittest cases passed, including the existing visual/capture/baseline suite and 32 semantic query, assertion, and CLI cases. |
| CLI contract | JSON and exit codes, invalid arguments rejected before app queries, source and region forwarding, semantic wait success and query errors. |
| Assertion policy | Text fields are matched individually, control names and roles are exact, scalar AX values are accepted, unknown/non-control enabled state cannot pass, incomplete and empty evidence cannot prove absence. |
| OCR policy and geometry | Mocked capture tests verify crop scaling and window-point bounds; weak confidence and OCR absence do not pass. Synthetic Vision recognition is described below. |
| Deadline and provenance | A slow subprocess is terminated; operational timeouts stay errors; valid nonmatching waits fail by timeout; saved inspection reports retain source, timestamp, window, options, and artifact paths. |
| Helper and packaging | Swift helper compiles; help/invalid-input contracts checked; cache reuse tested with a compiler stub; strict Claude plugin validation passed with version 0.7.0. |
| Existing utilities | 5 Excalidraw tests, all shell syntax checks, and relevant ShellCheck passed. |

## Synthetic Vision check

```bash
python3 tests/manual/verify_native_ocr.py
```

The actual Vision helper recognized `Canvas Evidence` from an 800 × 240 synthetic image with confidence 1.0 and a top-left pixel box of approximately `(41.75, 71.79, 324.49, 37.00)`. A blank image returned an empty list. The input image was visually inspected. Evidence is local at `.seer/qa/v07-synthetic-ocr-tiz_qoyh/report.json` and its adjacent PNG files. This exercises local recognition and pixel-coordinate conversion only; it does not validate screen capture, window-point conversion, or arbitrary text/languages.

## Native window checks still required

```bash
xcrun swiftc tests/manual/window_fixture.swift -o .seer/qa/SeerWindowFixture
python3 tests/manual/verify_v07.py
```

The fixture compiled, but the first live attempt could not capture its window and could not match it to an Accessibility window. A read-only session check confirmed `CGSSessionScreenIsLocked = 1`. The attempt is retained at `.seer/qa/v07-1k114rtf/report.json` and is not counted as a pass. No permission or lock setting was changed. The verifier now checks the lock before launching the fixture. The final preflight returned exit 2 with `blocked_reason: screen_locked` and launched no fixture; its record is `.seer/qa/v07-3omceg71/report.json`.

Resume this opt-in verifier in an unlocked desktop session and inspect its fresh PNG. Required scenarios include AX role/name/value/bounds/enabled, positive and negative text/control assertions, region filtering, delayed text success, valid nonmatch timeout, stale window IDs, OCR-only canvas text, confidence, region mapping, and insufficient OCR absence evidence. A successful native run is required before marking v0.7 complete or advancing the staged roadmap.

Actual permission denial, a hung real AX server, other macOS/Python versions, other display scales, and third-party app coverage remain untested. Public AX window matching requires a unique title/bounds match. The native helper bounds traversal by node count and depth and reports incomplete evidence; this cannot force an app to expose text it omits. The prior [v0.6 record](v0.6-validation.md) retains its visual fixture results and older doctor timeout limitation.

Inspection reports are saved locally. Assertion/wait verdicts are emitted on stdout and reference those reports; there is no semantic verdict replay command. The GitHub release and tag have not been published.

[Apple's AX timeout API](https://developer.apple.com/documentation/applicationservices/1459345-axuielementsetmessagingtimeout) and [Vision recognition API](https://developer.apple.com/documentation/vision/vnrecognizetextrequest) describe the underlying mechanisms; neither guarantees complete semantic evidence.
