# Seer v0.5 validation

This file is the historical v0.5 record. See [v0.6 validation](v0.6-validation.md) for the current checklist and evidence status.

This checklist separates deterministic command-stub coverage from actual macOS app evidence. Seven real-window scenarios passed on 2026-09-24; actual TCC permission-denial checks remain untested. No real baseline was created for this evaluation.

## What automated checks establish

The existing `tests/test_smoke.py` substitutes fake `osascript` and `screencapture` commands. `tests/test_capture_integrity.py` uses a fake capture command to check that valid PNG output replaces the destination and failed, partial, corrupt, or truncated output preserves it. These checks exercise CLI parsing, window IDs, subprocess arguments, JSON output, and capture integrity without controlling real macOS windows or privacy settings. CI also runs the dependency-free `skills/seer/scripts/test_excalidraw.py` regression suite after the smoke test. None of these checks prove actual Screen Recording or Accessibility behavior, capture real app pixels, or establish that a visual change is acceptable.

The real-window checks use the temporary AppKit fixture `tests/manual/window_fixture.swift`, which presents two independently colored, titled windows. Its runner `tests/manual/verify_window_ids.py` builds no app itself; from the repository root, build and run it as follows. It creates and controls only the fixture windows and writes captures plus `report.json` under `.seer/qa/`.

```bash
mkdir -p .seer/qa
swiftc tests/manual/window_fixture.swift -o .seer/qa/SeerWindowFixture
python3 tests/manual/verify_window_ids.py
```

The runner covers initial exact-window capture, movement, reordering, close/recreate, and preservation of an existing image after a stale-ID failure. It also checks that a missing baseline returns `needs_baseline` without creating a loop directory. It does not test actual permission denial. Do not revoke permissions from the user's active terminal. Actual TCC-denial checks are optional and should use an isolated test account or terminal with denied permissions; record them as untested unless that isolated setup is available.

Local automated checks passed: 24 unittest cases, 5 Excalidraw regression cases, shell syntax, ShellCheck, and `claude plugin validate --strict .`. Unit checks include JSON usage/subprocess errors, unavailable window access, independent doctor probes, PNG validation, and output preservation. They do not establish behavior across every macOS release or TCC configuration.

Never create or replace a real baseline during these checks without explicit user approval. The runner uses a fresh loop directory solely to verify the missing-baseline response.
