# Seer v0.8.0 release preparation

The package version is 0.8.0. No GitHub release or tag has been published.

## Changes

- Optional local stdio MCP adapter with `seer_run` and `seer_help`. Commands call the existing CLI; comparison, capture, OCR, and assertion logic stay in their original implementations.
- CLI JSON is preserved in MCP structured content and text, including status and local evidence paths. `fail` and `needs_baseline` remain valid outcomes; operational errors set MCP `isError`.
- Shared recovery guidance for CLI errors and missing baselines. Exact option spelling replaces undocumented argparse abbreviations.
- Bounded subprocess execution and cancellation cleanup, including native workers in separate process groups.
- Baseline writes are unavailable through MCP. The existing CLI approval workflow remains required for creation and replacement.
- Optional Python 3.10+ environment using official `mcp==2.2.0`; the standalone CLI still works without MCP on Python 3.9. Host examples cover Codex and Claude Code without changing saved configurations.

See [setup and host examples](../mcp-integration.md) and [validation evidence and limits](../v0.8-validation.md). The single Seer skill remains intact; splitting it requires evidence of repeated workflow confusion. Recording and typing remain specialist CLI scripts, outside the MCP tool surface.
