# Seer 0.7.0 — pending publication

**Publication status:** pending. These local notes do not announce a GitHub release or tag.

Seer 0.7 adds semantic inspection of a visible macOS window alongside its existing pixel-verification workflow.

- `inspect` reads Accessibility roles, names, values, bounds, and enabled state. Optional `--source ocr` runs macOS Vision OCR and returns recognized text, confidence, and bounds.
- `assert` checks text presence or absence, or a control's enabled state. Text is case-sensitive against individual AX name/value fields; control names match exactly. An enabled/disabled query may be restricted to an exact role; `--match` supports `contains` (default) and `exact` for text.
- `wait` retains `--stable` and also waits for semantic text or control conditions on one exact `window_id`.
- Accessibility is the default source. OCR must be selected explicitly; the CLI does not silently switch evidence sources. Optional regions use window-local points with a top-left origin. AX filters element-bound centers; OCR crops the corresponding pixels and translates recognized bounds back to the window.
- Incomplete, empty, truncated, timed-out, or weak evidence is an operational error, not a successful absence check. Complete AX absence applies only to the tree the app exposes. OCR supports confident positive text matches but cannot prove text absence or control state. A valid unmet assertion fails; a semantic wait continues through valid nonmatches until its deadline.
- Captured OCR images and semantic reports stay local under `.seer/inspect`. No model API key or external network is used.
- A first semantic query may compile the Swift helper into `.seer/cache`; this optional feature requires `swiftc` from Xcode Command Line Tools. Use a longer query timeout (for example, `--timeout 30`) when a cold build needs more time. Capture and visual verification do not require the helper.

Examples:

```bash
skills/seer/scripts/seer inspect --window-id 12345 --source ax --json
skills/seer/scripts/seer assert --window-id 12345 --text "Saved" --match exact --json
skills/seer/scripts/seer assert --window-id 12345 --enabled "Save" --role AXButton --json
skills/seer/scripts/seer assert --window-id 12345 --source ocr --text "Saved" \
  --min-confidence 0.8 --json
skills/seer/scripts/seer wait --text "Ready" --window-id 12345 --timeout 10 --interval 0.25 --json
```

Automated validation passed 78 unittest cases, 5 Excalidraw tests, shell checks, and strict plugin validation. The native helper compiled and Vision passed a synthetic-image check. Live window validation remains blocked by a locked desktop session; no successful live Accessibility or OCR window result is claimed.
