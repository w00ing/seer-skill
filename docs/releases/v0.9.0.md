# Seer v0.9.0 release preparation

The package version is 0.9.0. No GitHub release or tag has been published.

## Changes

- Markdown summaries from saved CLI results or verified comparison bundles, retaining the original verdict separately from report-generation success.
- Explicit local ZIP export of a manifest and its verified evidence files, with path checks and protection against overwriting outputs. Export preserves raw evidence; it does not anonymize or upload it.
- Minimal diagnostics with allowlisted environment and dependency information, without window queries, usernames, hostnames, paths, or credentials.
- Published JSON envelope and comparison-manifest schemas, an error-code reference, and compatibility rules for CLI/MCP consumers.
- Reproducible isolated skill install/update checks and synthetic verdict evaluation with success, false-pass, and timing measurements.
- An explicit CI test matrix and documentation separating measured native behavior from automated checks and untested environments.

The new maintenance commands are available through both the CLI and the existing two MCP tools. Comparison and assertion implementations, baseline approval requirements, and result schema version 1 remain in place. A small shared version module keeps diagnostics and the MCP server version available after copying the standalone skill.
