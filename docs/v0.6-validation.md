# Seer v0.6 validation

This is the historical v0.6 validation record. See [v0.7 validation](v0.7-validation.md) for the current semantic-query checks.

Validated on macOS 27.0 (Apple Silicon), Python 3.9.6, Pillow 11.3.0, and Swift 6.4. The native fixture rendered a 420 × 332 point window as an 840 × 664 PNG with approximately 144 DPI metadata. Other macOS versions, display scales, and real applications were not measured in this run.

## Automated checks

The unittest suite covers the existing CLI and capture contracts plus these v0.6 cases:

| Area | Verified behavior |
|---|---|
| Ignore rectangles | Overlap counts once; excluded pixels leave both numerator and denominator and are transparent in the diff. Changes outside the mask remain visible. |
| Invalid masks | Malformed, out-of-bounds, zero-sized, and fully excluded inputs fail. Invalid masks cannot create an approved baseline. Unified CLI errors use `invalid_arguments`. |
| Dimensions and DPI | Size mismatch and known PNG DPI mismatch fail without `--resize`; explicit normalization retains original dimensions/DPI in evidence. Unknown DPI remains unknown. |
| Stable wait | Repeated stable inputs pass; continuous changes time out; cumulative drift resets the interval anchor. Capture failure and malformed child responses are operational errors. |
| Bounded capture | A slow capture and its child process are terminated at the wait deadline; the parent removes their capture staging directory. |
| Capture metadata | The sidecar matches the image SHA-256, exact window ID, dimensions, and capture time. Stale metadata is reported as unknown. |
| Evidence | Baseline updates preserve the original comparison snapshot. Replay succeeds after sources change or disappear. Dimension errors preserve snapshots/report/manifest without a diff or baseline update. |
| Baseline approval boundary | Missing baseline returns `needs_baseline` without writing files. Creation and replacement require their explicit flags. Tests use disposable synthetic or fixture baselines only. |

Commands used:

```bash
python3 -m unittest discover -s tests -v
python3 skills/seer/scripts/test_excalidraw.py
for script in skills/seer/scripts/*.sh; do bash -n "$script"; done
shellcheck skills/seer/scripts/loop_compare.sh skills/seer/scripts/capture_app_window.sh
claude plugin validate --strict .
```

The Excalidraw suite passed 5 tests. Shell syntax, relevant ShellCheck, and strict plugin validation passed. The final unittest run passed all 46 tests in 49.275 seconds.

## Native fixture evidence

```bash
mkdir -p .seer/qa
swiftc tests/manual/window_fixture.swift -o .seer/qa/SeerWindowFixture
python3 tests/manual/verify_v06.py
```

All 6 scenarios passed. Fresh static and masked captures were inspected visually: the changing patch remained confined to its intended rectangle.

| Scenario | Observed result |
|---|---|
| Static window | Stable after 2 samples, 3.523 seconds. |
| Animation settles | Stable after 3 samples, 5.536 seconds. |
| Continuous animation | Timeout after 3 samples, 6.023 seconds; existing PNG and sidecar stayed byte-identical. |
| Animation inside the mask | Stable after 2 samples, 3.831 seconds. |
| Animation outside the mask | Timeout after 3 samples, 6.008 seconds; no output published. Both timeout scenarios observed changed pixels before the deadline. |
| Evidence replay | Same verdict and metrics after original baseline/current paths were moved away. |

The mask was derived from captured pixels: `76,436,200,152` within the 840 × 664 PNG. These elapsed times describe this fixture run, not a general performance guarantee.

## Limits and investigation notes

- An attempted rerun of the older `verify_window_ids.py` suite discovered the fixture windows but timed out in the unchanged `doctor` call after 20 seconds. That attempt is not counted as a passing v0.6 check; its local record is `.seer/qa/window-ids-m5wtk7xk/report.json`. The new v0.6 fixture checks exact-window capture directly. Earlier window lifecycle evidence remains in [v0.5 validation](v0.5-validation.md).
- The first v0.6 fixture trial revealed that its drawing callback painted outside a patch. The fixture was corrected to paint only its bounds and all six scenarios were rerun. The failed trial is retained locally as `.seer/qa/v06-fmiub2uw/report.json`.
- Actual Screen Recording/Accessibility permission denial was not induced. Existing command-stub failures do not prove real TCC behavior, and no privacy settings were changed.
- Pixel similarity and sampled stability do not establish semantic UI correctness.
- The v0.6 GitHub release and tag have not been published.
